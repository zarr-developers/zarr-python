A definition's rules are located where the document writes the field. A
    `bytes` codec written as `"bytes"` or `{"name": "bytes"}`, with values
    of several bytes, reports its missing `endian` at
    `codecs.N.configuration`, the configuration it does not write, as a
    codec that requires a configuration does; it was reported at
    `codecs.N.configuration.endian`, inside a configuration that is not
    there. A problem with such a field's configuration as a whole, such as a
    data type of varying size, is at the field. This holds for a
    definition's `rules` and a codec's `chunk_rules` alike.

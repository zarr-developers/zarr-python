Reading a v3 group no longer reads the documents in its
`consolidated_metadata`. The group checks the envelope that the core spec
fixes, and `ZarrV3GroupMetadata.consolidated_metadata` is now that member
as written, a read-only JSON object, instead of a
`ZarrV3ConsolidatedMetadata`. A group whose consolidated metadata lists a
broken document now opens, and the document fails only when it is read.
To read the listed documents, pass the member to
`ZarrV3ConsolidatedMetadata` or to the new `read_consolidated_metadata_v3`,
or read one with `read_node_metadata_v3`. To write consolidated metadata,
pass a `ZarrV3ConsolidatedMetadata` to the group's `update`.

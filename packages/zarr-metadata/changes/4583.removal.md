Rename the v3 scopes `CORE` and `CORE_AND_EXTENSIONS` to `CORE_CONTEXT` and `CORE_AND_EXTENSIONS_CONTEXT`, so that a scope's name says it is a `ZarrV3Context`. The old names, imported from `zarr_metadata.v3` or `zarr_metadata.v3.definition`, still refer to the same scopes with a `DeprecationWarning`, and will be removed in a later release.

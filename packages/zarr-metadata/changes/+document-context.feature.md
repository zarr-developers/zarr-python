A v3 model is its document and the scope it was read in: `ZarrV3ArrayMetadata(document, context=None)` reads the document in the scope, `to_json` writes it as it was written, and `update` reads new members in the model's own scope, so no scope is passed back in. `with_context` reads the document in another scope; `refined_in` does so only when that scope claims what this one left unclaimed and contradicts nothing, raising `ScopeConflictError` otherwise; `refines` says whether one model holds everything another does. The documents a group's consolidated metadata holds are models of the group's scope, built from one read.

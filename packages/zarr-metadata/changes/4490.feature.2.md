**Breaking:** a member of a v3 document that the spec does not define is
now read as an extra field. A scope can define one by its key, with
`ArrayExtraFieldDefinition` or `GroupExtraFieldDefinition` in the
`array_extra_fields` or `group_extra_fields` slot of `ZarrV3Context`, and
the member is then checked like any other field. A model's
`extra_fields` now holds fields (`AcceptedField` or `UnclaimedField`)
instead of JSON values, and `must_understand_fields` lists only the
members that no definition in scope reads, which are the members a
reader must refuse. `CORE` reads a group's `consolidated_metadata` with
`CONSOLIDATED_METADATA_EXTRA_FIELD`. `UserJSONValue`, in
`zarr_metadata.typed_json`, types a configuration member that holds user
data, whose numbers may be `NaN`, `Infinity` or `-Infinity`.

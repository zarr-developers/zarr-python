Reading a metadata document is 2.5 to 4 times faster: a document is refined
to JSON once, the model holds what was refined, and a model's key -- what
`==` and `hash` compare -- is computed the first time the model is compared
rather than when it is built, so a definition's `canonical` is first asked
then. Every problem is reported as before, with the same `loc`, `kind`,
message and `input`. The typed members a model shows are the refined values
throughout: `dimension_names`, a v2 group's `attributes`, and a v2 array's
`order` and `dimension_separator`, which are now judged as refined, so a
value that only compares equal to `"C"` or `"."` without being a string is
refused.

`read_repaired_node_metadata_v3` reads a v3 `zarr.json` after fixing known writer bugs and returns the list of repairs it made. It covers a chunk length of 0 along an empty dimension (zarr-python 3.0 and 3.1) and `consolidated_metadata: null` (zarr-python 3.0.x). `repair_node_metadata_v3` does only the repair; the strict readers still refuse these documents.

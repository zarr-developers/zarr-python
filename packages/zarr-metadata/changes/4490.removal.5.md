**Breaking:** the `attributes` of a `ZarrV2ArrayMetadata` or `ZarrV2GroupMetadata` is now always a mapping, empty when there is no `.zattrs`, as on the v3 models. It was `UNSET` before. `to_json` and `to_key_value` still write the attributes and `.zattrs` only when a `.zattrs` exists, and `update(attributes=UNSET)` still removes it. A node with no `.zattrs` and one with an empty `.zattrs` now compare equal, as a v3 document with and without an empty `attributes` do. The two still write different files, because only one of them writes a `.zattrs`; compare their `to_key_value()` to tell them apart.

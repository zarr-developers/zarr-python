**Breaking:** the `attributes` of a `ZarrV2ArrayMetadata` or `ZarrV2GroupMetadata` is now always a mapping, empty when there is no `.zattrs`, as on the v3 models. It was `UNSET` before. `to_json` and `to_key_value` still write the attributes and `.zattrs` only when a `.zattrs` exists, and `update(attributes=UNSET)` still removes it.

A group's consolidated metadata is judged as the hierarchy below the
group: a key that is no node's path, such as `""` or `"a/../b"`, a
document below an array's, and a document whose parent group is missing
are problems, where they were read without one. A `zarr.json` of no
node type the spec defines is judged by its `zarr_format` too, so a v2
document, or the root of zarr-python 2's draft of v3, is reported as
not v3 rather than only as missing its `node_type`.

A `zarr.json` that says no node type the spec defines is judged by its
`zarr_format` too, so a document of another format says it is not v3.
The root `zarr.json` of zarr-python 2's draft of v3, whose `zarr_format`
is a URL, was reported only as missing its `node_type`; it now also has
an `invalid_type` problem at `zarr_format`, and a v2 document read as a
`zarr.json` an `invalid_value` there.

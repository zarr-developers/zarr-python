Extension names must match `^[a-z][a-z0-9-_.]+$` or be a URI in RFC 3986 characters. Any other name (`""`, `"foo/bar"`) is refused with an `invalid_value` problem at `name` before any definition is looked up; before, every string was read as an unknown extension. `well_named` checks a string, `validate_metadata_field_v3` enforces the rule, the JSON Schema carries the same pattern, and a definition built with an invalid name raises `TypeError`.

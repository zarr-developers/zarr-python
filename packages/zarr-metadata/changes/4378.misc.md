**Breaking:** `MetadataValidationError.problems` is now a tuple instead of
a list. The `validate_*` functions in `zarr_metadata.model`,
`validate_node_name_v3` and `validate_node_path_v3`, return
`tuple[ValidationProblem, ...]` too. Iteration and indexing are
unchanged; callers that mutate reports must first copy them with
`list(problems)`. `MetadataValidationError` still accepts any problem
sequence.

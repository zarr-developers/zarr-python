**Breaking:** A problem in a v2 struct dtype is located where the document
    writes it. A record's problem was located under a `fields` key the
    document does not have, at `("dtype", "fields", 0, 1)`; it is now at
    `("dtype", 0, 1)`, and carries the value found there as its `input`.
    `fields()` places each record's type there too. A definition's
    functions still find the record types in `nested` at
    `("fields", 0, 1)`, their place in the configuration.

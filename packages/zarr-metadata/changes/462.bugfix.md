A v3 codec's `chunk_canonical` receives the configuration as the codec's `canonical` spells it, so two spellings that `canonical` reduces to one are simplified for a chunk in the same way. Before, it received the configuration as written, and array models that differed only in such spellings were unequal. The result of `chunk_canonical` is also checked to have nothing left to simplify: a `chunk_canonical` that changes its own result raises `ValueError`.

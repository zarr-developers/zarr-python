`zarr_metadata.pydantic.InScope` fixes a field's scope: `Annotated[ZarrV3ArrayMetadata, InScope(CONTEXT)]` reads in `CONTEXT` whatever the validation context holds. A model instance given to a field read in an explicit scope is now read again in that scope, so one that scope reads differently is refused rather than passed through, and a misspelled `zarr_metadata...` key in the validation context raises `TypeError`.

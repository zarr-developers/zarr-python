`v3/_typed_json` is the type checker the entity layer will read
metadata with, on its own: for each shape JSON takes -- `int`, `float`,
`bool`, `str`, `JSONValue`, a `Literal`, `tuple[T, ...]` and
`tuple[T1, T2]`, a union, a TypedDict, a record dataclass,
`Mapping[str, V]`, a `NewType`, and `| UNSET` for a member a document may
leave out -- a parser compiled once from the annotation, and the writer
that is its inverse. A parser is `(value, loc, state) -> (typed value,
problems)`, generic in a state it hands through, and a caller's leaf is
asked first at every depth for shapes of its own. `field_hints` resolves
a dataclass's annotations where each class was defined and skips class
variables; `declared_class_vars` reports those. The module knows nothing
of entities.

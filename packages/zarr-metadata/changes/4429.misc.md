**Breaking:** for type checkers, every `is_*` guard in `zarr_metadata.model`
is declared `TypeGuard` rather than `TypeIs`. Each returns False for some
values of its type: `is_json(math.nan)` is False though a NaN is a
`float`, and a document can be well typed and structurally invalid. A
`TypeIs` told type checkers to narrow such a value away when the guard
said no, so code that type-checked could fail at run time. True narrows as
before; False no longer narrows.

A v2 array document that omits `dimension_separator` is now written back
without it: `to_json` and `to_key_value` no longer add
`"dimension_separator": "."`. The model's `dimension_separator` is still
`"."`, and the model still compares equal to one whose document writes
`"."`. Removing the key with `update(dimension_separator=UNSET)` now takes
effect in the written document.

`ZarrV3Context.update` and `ZarrV2Context.update` return the scope with each slot they are given replaced, and keep the other slots. A slot can be given as definitions or as a mapping from each definition's name to it, such as another scope's slot, so `context.update(codecs={**context.codecs, "gzip": MY_GZIP})` replaces one definition and `context.update(codecs=[*context.codecs.values(), MY_CODEC])` adds one. A key that is not its definition's name raises `TypeError`.

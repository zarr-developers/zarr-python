`LazyArray.write` no longer promises that the last of several writes to one source cell wins: the cell receives one of the values written to it, whole, but which one is unspecified, so remove repeated indices from a selection whose result matters. `IndexedSet` and `JointSet` no longer order the points within a row either. Without these promises, planning groups points with an unstable sort and writes skip deduplication, so partitioning a large unordered selection is up to 36% faster and a fancy write to a NumPy array about 10x faster.

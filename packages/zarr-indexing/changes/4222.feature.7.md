The algebra's types carry their own operations. `IndexTransform` composes
(`outer.compose(inner)`), applies a selection in any dialect
(`transform.select(selection, mode)`), locates coordinates (`apply`,
`apply_many`), reports how its index arrays relate to its input axes
(`index_array_structure`), and serializes (`to_json` / `from_json`, with the
same pair on `IndexDomain` and `to_json` on each output map kind). An `ArrayMap`
reports the axes it varies over — `dependency_axes`, and `dependent_axis` for
the orthogonal case — read from its full-rank index array's shape, which is the
single source of truth for what a map depends on; a selection narrowed to one
coordinate is built as the `ConstantMap` it equals, so a length-1 fancy
selection classifies as a box. `ArrayMap`, `IndexTransform` and `Partition`
compare and hash as the values they are.

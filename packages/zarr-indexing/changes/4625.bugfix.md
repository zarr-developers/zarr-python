The `lazy_indexing_numpy` and `lazy_indexing_dask` examples, and `test_cli_example_runs_as_a_subprocess`, which runs them, pass under pytest 9.2. The examples passed `-c` and their own path to `pytest.main` as one argument, which pytest 9.2 rejects. They now pass `-c os.devnull`, so pytest reads no configuration file, and they no longer leave a directory named ` ` (a single space) in the working directory under earlier pytest releases.

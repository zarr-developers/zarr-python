Initial release of `zarr-chunk-key-encoding`: the `ChunkKeyEncoding` abstract
base class, the spec-defined `DefaultChunkKeyEncoding` and
`V2ChunkKeyEncoding`, strict decoding, and JSON round-tripping through
`chunk_key_encoding_from_json`, built on `zarr-metadata` types.

`ChunkKeyEncoding.to_bounded` prepares an encoding for repeated operations
against one chunk or shard grid. It validates the grid shape once, then checks
coordinates and decoded keys against it. The package covers only the closed
set defined by the Zarr v3 core specification and provides no registration or
plugin-discovery API.

Partial reads of uncompressed chunks now narrow past the first axis. When `BytesCodec` is the only codec and a selection takes a single index along the leading axes, the byte range request covers only the rows it touches along the next axis. For example, `arr[t, y0:y1, x0:x1]` fetches rows `y0` to `y1` of frame `t` instead of the whole frame, and a single element is fetched for a point.

Array metadata that uses Zarr V3.1 short-hand extension names, such as
`"codecs": ["bytes", "crc32c"]` or `"chunk_key_encoding": "default"`, can now be
read. A bare name is read as an object with only a `name` key. Previously, such
metadata raised `TypeError: Expected dict, got <class 'str'>`. Metadata is still
written in the object form, which Zarr V3.0 readers require.

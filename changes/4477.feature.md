Added a builtin, read-only `zip:` URL pipeline adapter for addressing data inside a ZIP
archive, e.g. `zarr.open_group("s3://bucket/data.zip|zip:inner-dir|zarr3:subgroup")`. The
archive can be a local file, an fsspec object, or an entry of another archive
(`outer.zip|zip:inner.zip|zip:`), and is read with async byte-range requests. Writable
modes (`"w"`, `"w-"`, `"r+"`) raise `URLPipelineError` for now; mode `"a"` opens the
archive read-only.

Added ``Array.prepend``, which adds data before index 0 of an axis without moving existing chunks.
The array's lower bound is read from and written to the ``bounds`` metadata member of ZEP 12
(``inclusive_min`` / ``exclusive_max``, in place of ``shape`` once a lower bound is non-zero; later
updates keep whichever form the document has), chunk grid indices on a ``regular`` grid can be
negative, and ``Array.domain`` reports the coordinate range of each dimension. Added the ``offset`` chunk grid, which shifts a ``regular`` base grid so
that its chunk 0 begins at a chosen coordinate. Chunk keys with a ``-0`` component are now rejected.

Scalar indexing on a Zarr array (e.g., `a[0]` on a 1D array, or `a[i, j]` on a 2D array) now returns a NumPy scalar instead of a 0-d `numpy.ndarray`, matching the behavior of NumPy, h5py, and Zarr v2. The fix broadens the scalar conversion in `_get_selection` from `isinstance(indexer, BasicIndexer)` to `indexer.shape == ()`, so it covers both `BasicIndexer` and `OrthogonalIndexer` paths (integer indexing on a 1D array is dispatched to `OrthogonalIndexer` via `__getitem__`). Also updates two doctest examples in `__getitem__` to reflect the corrected output. Fixes #3741.

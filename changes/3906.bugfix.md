Unsigned integer index arrays now work with `Array.oindex` and `Array.vindex`. Previously a
descending or unordered `uint` index array was classified as increasing (the ordering check
differenced adjacent elements, and on an unsigned dtype a descending difference wraps around to a
large positive value), which returned data for the wrong chunk region or raised `IndexError`;
`uint64` index arrays raised `IndexError` in all orderings, because mixing them with the signed
chunk offsets promoted the selection to `float64`. Index arrays with an unsigned dtype are now
converted to a signed index dtype up front, and a value too large to be a valid index raises
`BoundsCheckError` instead of wrapping around to a negative index.

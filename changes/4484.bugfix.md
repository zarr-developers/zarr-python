Creating a node now raises `MetadataValidationError` when a name segment is `zarr.json`, begins with `__`, or is `.` or `..`. Previously `create_group("a/zarr.json")` wrote a directory named `zarr.json` that shadowed the group's metadata document and left the subtree unreachable. `create_group("__a")` likewise wrote a reserved name. Both are refused before anything is stored. Covered are `AsyncGroup.create_group`, `AsyncGroup.create_array`, and the `name`/`path` arguments of the module-level `create_array` and `create_group`.

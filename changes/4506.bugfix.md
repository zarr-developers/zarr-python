Array metadata that uses Zarr V3.1 short-hand extension names, such as
`"codecs": ["bytes", "crc32c"]` or `"chunk_key_encoding": "default"`, can now be
read. A bare name is read as an object with only a `name` key. Previously, a
short-hand codec or chunk key encoding raised
`TypeError: Expected dict, got <class 'str'>`, and a short-hand storage
transformer was kept as a bare string. Metadata is still written in the object
form, which Zarr V3.0 readers require. The `chunk_key_encoding` parameter of
`create_array` and the other array creation functions also accepts a bare name,
such as `chunk_key_encoding="v2"`.

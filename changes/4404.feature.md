Reading data encoded with the `pickle` codec now requires an explicit opt-in, because unpickling data from an untrusted store can execute arbitrary code. Enable it with `zarr.config.set({"array.allow_pickle": True})` or the environment variable `ZARR_ARRAY__ALLOW_PICKLE=True`. Without the opt-in, reading such data raises `zarr.errors.PickleCodecDisabledError`. Writing with the `pickle` codec is unchanged.

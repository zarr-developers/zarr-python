Iterating over an array (`for row in array`) now reads the array one row of chunks (of shards, for a sharded array) at a time and yields the rows from each block, instead of reading `array[i]` separately for every row. A full pass now reads and decodes each chunk once rather than once per row it holds, which makes iteration orders of magnitude faster. The rows yielded are unchanged. At most one block is held in memory at a time, capped by the new `array.iter_block_max_bytes` config value (default 128 MiB). Iterating over a 0-d array now raises `TypeError`, as it does for NumPy arrays, instead of yielding nothing.

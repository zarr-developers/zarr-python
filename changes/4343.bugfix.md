Fix several small bugs in `Group` and `sync`: `Group.members` and `AsyncGroup.members` now honor `use_consolidated_for_children=False` when the group itself has consolidated metadata, and forward the flag when recursing; `Group.update_attributes_async` now merges new attributes into the existing ones instead of replacing them, matching `Group.update_attributes`; `sync()` now cancels the pending coroutine when it times out instead of leaving it running on the IO thread; the deprecation warning for `zarr.storage.default_compressor` no longer points at a removed config key; and the GPU `NDBuffer.create` zero-fills when no fill value is given, matching the CPU buffer.

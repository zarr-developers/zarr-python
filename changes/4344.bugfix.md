Resizing an array with `delete_outside_chunks=True` now generates only the
out-of-bounds chunk coordinates and deletes them with a bounded pool of
workers, instead of materializing the entire old and new grids and all
deletion tasks. This bounds auxiliary memory during shrinking and mixed
growing/shrinking resizes while preserving retained chunks. Growing, or
shrinking within the last chunk of each axis, no longer schedules any
deletion work. When a deletion fails, the remaining deletions are now
cancelled before the error is raised; previously they ran to completion.

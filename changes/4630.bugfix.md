`zarr migrate v3` now migrates Zarr format 2 arrays compressed with
`Blosc(shuffle=Blosc.AUTOSHUFFLE)`. The v3 Blosc codec gets the shuffle that
numcodecs used for the array's item size: `bitshuffle` for 1-byte items and
`shuffle` otherwise. Before, the migration failed with
`ValueError: Value must be between 0 and 2. Got -1.`

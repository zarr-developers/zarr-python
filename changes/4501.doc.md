Defined the public API in the contributing guide: the top-level `zarr` namespace and the modules, names, and behavior documented in the API reference. `zarr.core`, underscore-prefixed names, undocumented imports, and `zarr.experimental` are private. Added the missing API reference page for `zarr.types`, whose names were made public in 3.3.0. `ci/check_documented_exports.py` now counts a module's members the way mkdocstrings renders them, so a name imported by a documented module no longer counts as documented.

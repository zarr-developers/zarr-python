`arr[[]]`, and the same empty-list selection inside a tuple, an `oindex` selection or a `vindex` selection, used to raise `IndexError: unsupported selection item for basic indexing`, even though `IntSequence`, the declared selection type, includes `list[int]` and the same selection written as an empty integer array already worked. An empty list is now treated as an empty integer selection, matching NumPy, so `arr[[]]` returns an empty array instead of raising.

A structured data type now resolves its field data types with the data type registry that resolves it, instead of always using the default registry. `get_data_type_from_json`, `get_data_type_from_native_dtype`, `parse_dtype` and `parse_data_type` take an optional `registry`, and `Structured.from_json` / `Struct.from_json` take an optional `resolver` (see `zarr.dtype.DTypeResolver`). Data types registered through the `zarr.data_type` entry point group are now loaded; previously they were collected but never registered.

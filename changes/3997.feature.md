Added `zarr.run`, a public function for running Zarr's asynchronous API from synchronous code. It runs a coroutine to completion on Zarr's managed event loop by default, or on an explicitly supplied loop, and returns the result. Calling it from the target loop's thread raises `RuntimeError`. A different running loop on the calling thread does not prevent dispatch, but that thread is blocked; prefer awaiting the async API directly in async code.

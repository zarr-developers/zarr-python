Added a Deprecations page that indexes every deprecated API with its migration
path and planned removal. Both of its tables are generated from the source: the
message of each `@deprecated` decorator, which is now also rendered in the API
reference, and the declarations in `zarr._deprecations`, through which every
other deprecation warning is raised. A test fails if a deprecation warning is
raised any other way, so no deprecation can go undocumented.

Added core support for URL pipelines (https://github.com/jbms/url-pipeline), `|`-chained
URLs such as `s3://bucket/data.zip|zip:|zarr3:`. Parse one with
`zarr.storage.URLPipeline.from_url` and pass it to any function that accepts a `StoreLike`;
plain strings are never read as pipelines. A trailing `zarr:`, `zarr2:` or `zarr3:` segment
gives the node path and selects (or detects) the format. Packages provide adapters for other
schemes by subclassing `zarr.abc.url_pipeline.URLPipelineAdapter` and registering it under the
`zarr.url_adapters` entry-point group or with `zarr.registry.register_url_adapter`.

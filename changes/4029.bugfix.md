`zarr.storage` is no longer replaced by a `ModuleType` subclass at import time.
The subclass only existed to warn about the long-deprecated
`zarr.storage.default_compressor` attribute, but serializers that dispatch on
the exact type of an object (such as `cloudpickle`, which Dask uses by default)
could not serialize the module and raised
`TypeError: cannot pickle 'VerboseModule' object`. Setting
`zarr.storage.default_compressor` no longer emits a deprecation warning; use
`zarr.config` to configure `array.v2_default_compressor` instead.

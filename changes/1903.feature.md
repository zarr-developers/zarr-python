Added official support for the Pyodide/WebAssembly platform, for using Zarr v3 within browser-based environments.
Zarr's thread-based machinery is unavailable on this platform, as no IO thread or thread pool is created. The
synchronous API relies on the
[JavaScript Promise Integration (JSPI)](https://github.com/WebAssembly/js-promise-integration) WebAssembly
feature to block on asynchronous work, which Pyodide enables by default. In environments without JSPI, use the
async API via `zarr.api.asynchronous` instead.

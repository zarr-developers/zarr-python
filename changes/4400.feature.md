Writing attributes with non-string keys, which JSON stores as strings, now emits a `ZarrFutureWarning`: this will become an error in a future version. Two new config options control how attributes that are not valid JSON are written: `attributes.non_string_keys` (default `"warn"`) and `attributes.non_finite_floats` for `NaN` and infinite values (default `"allow"`). Each takes `"allow"`, `"warn"` or `"raise"`.

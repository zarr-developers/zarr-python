Preserve non-canonical NaN payloads in v3 fill values. Only the exact
canonical NaN bit pattern, sign bit included, serializes as `NaN`; every
other NaN, including the negative-sign form of the canonical payload,
writes back as its hex bits, and hex strings decode into same-width
NumPy scalars so float16 payloads survive. `ArrayV3Metadata` equality
now compares the serialized JSON text without sorting keys, so attribute
dictionaries with mixed key types no longer raise `TypeError`; as a
consequence of comparing JSON text, attributes that differ only in JSON
spelling, such as `1` and `1.0`, no longer compare equal. This also
stops equality from conflating `-0.0` with `0.0`. Partial fix for issue
#4453.

A structured data type read by a `DataTypeRegistry` now resolves its field data types with that registry, instead of always with the default registry. A structured data type with a field whose data type matches no data type now reports the location of that field in the JSON (e.g. `at /configuration/fields/1/data_type`), instead of reporting that the whole structured data type matches nothing. Data types registered through the `zarr.data_type` entry point group are now loaded; previously they were collected but never registered.
